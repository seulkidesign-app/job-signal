# Job Signal

**국내 채용공고를 목록이 아니라 ‘현재 시장 신호’로 읽는 채용시장 인덱스.**

여러 채용 플랫폼에 흩어진 공고를 직무 단위로 정리해 현재 채용량, 경력 요구, 채용 기업, 원천 플랫폼과 시간에 따른 변화를 빠르게 확인하는 실험입니다.

## Public beta

- Website: https://seulkidesign-app.github.io/job-signal/
- 우선 지원 직군: **디자인 / PM·기획 / 마케팅 / 데이터 / 백엔드**
- 공고마다 원문 링크, 출처, 경력, 고용형태, 검증일을 함께 저장합니다.
- 결과가 없는 검색어에 가짜 데이터나 임의의 숫자를 표시하지 않습니다.
- 마감이 확인된 공고는 활성 시장 데이터에서 제외합니다.

## 왜 만들었나

채용 플랫폼은 ‘내가 지원할 공고’를 찾는 데 최적화되어 있지만, 다음 질문에는 답하기 어렵습니다.

- 지금 이 직무는 실제로 얼마나 뽑고 있는가?
- 신입이 들어갈 자리가 늘고 있는가, 줄고 있는가?
- 최소 5년 이상을 요구하는 비중은 어떻게 변하는가?
- 어떤 기업이 지금 적극적으로 채용하는가?
- 일주일 전과 비교해 시장이 좋아지고 있는가?

Job Signal은 개별 공고 탐색 위에 **시장 분석 레이어**를 만드는 것을 목표로 합니다.

## 자동 갱신 구조

```text
공식 API / 허용된 공개 데이터 경로
        ↓
30분 단위 scheduled sync
        ↓
활성 공고 정규화 + 중복 제거 + 마감 제거
        ↓
data/jobs.json
        ↓
시간축 스냅샷 data/history.json
        ↓
GitHub Pages 자동 재배포
```

현재 `scripts/sync-live.js`와 `.github/workflows/live-sync.yml`이 자동 동기화를 담당합니다. 공식 API 키가 설정되지 않았거나 모든 라이브 호출이 실패하면 **기존 정상 데이터는 덮어쓰지 않습니다.**

### 현재 데이터 상태

- **사람인**: 공식 채용정보 API 어댑터 구현 완료. `SARAMIN_ACCESS_KEY`가 설정되면 30분 단위 자동 동기화.
- **잡코리아**: 공식 채용정보 API 제공 여부/승인 조건을 따르는 방식으로 연결 예정.
- **원티드**: 공식 OpenAPI의 Jobs 권한을 통한 연결을 우선합니다.
- **리멤버 / 직행**: 공식적으로 허용된 자동 연동 경로가 확인되기 전에는 실시간이라고 표시하지 않습니다.
- 자동 연결이 없는 플랫폼은 최근 직접 검증한 공개 공고만 보강 데이터로 사용합니다.

## 시장 변화 추적

자동 동기화가 실행될 때마다 `data/history.json`에 직무별 스냅샷을 저장합니다.

- 현재 검색 공고 총량
- 신입·1년 이하 비중
- 최소 5년 이상 비중
- 활성 공고 표본 수

7일 이상의 데이터가 쌓이면 웹에서 **7일 전 대비 채용량 변화와 경력 비중 변화**를 실제 관측값으로 표시합니다. 데이터가 충분하지 않을 때는 `추세 데이터 축적 중`으로 표시하며 가짜 변화율을 만들지 않습니다.

## 데이터 원칙

1. 화면에 현재 연결된 데이터 범위와 갱신 상태를 명시합니다.
2. 표본을 전체 국내 채용시장처럼 과장하지 않습니다.
3. 동일 기업·동일 공고는 중복 집계하지 않습니다.
4. 자동 수집은 공식 API 또는 명시적으로 허용된 경로를 우선합니다.
5. 외부 플랫폼의 이용정책을 우회하는 크롤링을 기본 데이터 전략으로 사용하지 않습니다.
6. API 장애나 빈 응답이 발생해도 정상 데이터셋을 빈 값으로 덮어쓰지 않습니다.

## Reliability

모든 `main` push에서 GitHub Actions QA가 다음을 검사합니다.

- 브라우저 JavaScript 문법
- 서버리스 API 문법
- 자동 sync 스크립트 문법
- 공고 데이터 필수 필드 / URL / ID 중복
- 추세 히스토리 구조
- 핵심 UI hook 존재 여부
- API fallback smoke test
- API key가 없는 환경에서 sync가 안전하게 종료되는지

## Local run

정적 화면:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 됩니다.
