# Data source policy

_Last reviewed: 2026-08-17_

Job Signal의 핵심 원칙은 **데이터 범위를 숨기지 않고, 플랫폼 정책을 우회하지 않는 것**입니다.

## 사람인

- 공식 채용정보 Open API 제공.
- 이용신청 승인 후 access key 발급 필요.
- 현재 `api/jobs.js`에 공식 API 어댑터 구현 완료.
- `SARAMIN_ACCESS_KEY`가 설정되지 않으면 검증 스냅샷으로 자동 폴백.
- 화면에서 사람인 제공 데이터와 검증 스냅샷을 구분해 표시.
- API 제공 주체를 오인시키지 않으며, 상용화 전 이용조건을 다시 검토.

Official docs:
- https://oapi.saramin.co.kr/introduce
- https://oapi.saramin.co.kr/guide/job-search
- https://oapi.saramin.co.kr/caution

## 잡코리아

- 잡코리아 사이트에 채용정보 API/Open API 안내와 XML 응답 샘플이 공개되어 있음.
- 실제 프로덕션 연동에 필요한 현재 승인/인증 방식이 확인될 때까지 자동 수집 어댑터를 활성화하지 않음.
- 화면/스냅샷에 포함할 경우 공개 상세 공고 링크와 출처를 명시.

Reference:
- https://company.jobkorea.co.kr/Network/Popup_Xml_sample_1.asp

## 원티드

- 공개 채용공고 페이지의 안내에 무단 전재·재배포·재가공·크롤링 금지가 명시되어 있음.
- 따라서 공개 페이지를 대상으로 한 자동 크롤러를 Job Signal의 기본 수집 방식으로 사용하지 않음.
- 공식 허가/제휴/API가 확보되기 전에는 최소 메타데이터의 검증 스냅샷과 상세 링크만 사용.

## 리멤버

- 공개 채용 상세 페이지를 통해 개별 공고를 검증할 수 있음.
- 현재 공개적으로 확인 가능한 범용 채용 API가 확보되지 않아 자동 크롤링을 기본 전략으로 사용하지 않음.
- 공식 API/제휴 경로가 확인되면 어댑터 방식으로 추가.

## 직행

- 여러 채용 플랫폼의 공고를 모아 보여주는 공개 서비스이며, 공고 페이지에서 원천 출처를 확인할 수 있는 경우가 있음.
- Job Signal은 직행을 복제하는 공고 모음 서비스가 아니라, 공고 메타데이터를 직무 시장 신호로 해석하는 분석 레이어를 목표로 함.
- 공식 API/제휴 경로가 확인되기 전에는 자동 대량수집에 의존하지 않음.

## Snapshot policy

- 각 row에 `source`, `url`, `verified_at`을 저장.
- 날짜형 마감일이 지난 공고는 화면에서 자동 제외.
- 동일 기업 + 동일 제목은 중복 제거.
- 결과 수는 현재 연결된 데이터의 **분석 표본**으로 표현하고 전체 시장 총량으로 표현하지 않음.
