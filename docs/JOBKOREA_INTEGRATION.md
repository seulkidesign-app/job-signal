# 잡코리아 연동 메모

잡코리아 공식 사이트 하단에서 Open API 메뉴를 제공하는 것은 확인되었습니다. 다만 현재 공개 웹에서 Job Signal에 필요한 채용공고 조회 명세·인증 방식·재사용 조건까지 충분히 확인되지 않아, 비공식 endpoint나 크롤링으로 구현하지 않습니다.

## 문의 목적

Job Signal은 국내 채용시장을 직무별로 분석하는 무료 서비스이며, 잡코리아 채용공고의 제목·회사·경력·지역·마감일·원문 URL 등 최소 메타데이터를 승인된 방식으로 정기 동기화하고자 합니다.

## 문의 문구 초안

안녕하세요. 국내 채용시장의 직무별 채용량, 요구 경력, 채용 기업 및 시간에 따른 변화를 분석해 보여주는 무료 서비스 Job Signal을 개발하고 있습니다.

잡코리아 채용공고의 최소 메타데이터(공고 ID, 제목, 회사명, 직무, 지역, 경력, 고용형태, 등록일/마감일, 원문 URL)를 주기적으로 조회하여 통계적으로 집계하고, 개별 공고에는 잡코리아 원문 링크와 출처를 명확히 표시하려고 합니다.

공식 Open API 또는 제휴 API를 통해 해당 데이터를 사용할 수 있는지, 신청 절차와 이용 조건, 호출 제한, 출처 표기 조건을 안내받고 싶습니다. 비공식 크롤링은 사용하지 않을 계획입니다.

서비스 URL: https://seulkidesign-app.github.io/job-signal/

## 연결 원칙

공식 문서/승인 정보가 확보된 뒤에만 어댑터를 구현합니다. 승인 전에는 직접 검증한 공개 공고만 제한적으로 사용하고 LIVE라고 표시하지 않습니다.
