# 사람인 API 신청용 문구

## 서비스명

Job Signal

## 서비스 URL

https://seulkidesign-app.github.io/job-signal/

## 이용 목적 — 복사해서 사용

Job Signal은 국내 채용공고를 단순 목록으로 제공하는 것이 아니라, 직무별 현재 채용량과 요구 경력, 채용 기업, 공고 변화 추이를 한눈에 파악할 수 있도록 분석하는 무료 채용시장 정보 서비스입니다. 사람인 채용정보 API를 활용해 디자인, 프로덕트/기획, 마케팅, 데이터, 개발 직군의 현재 활성 공고를 정기적으로 갱신하고, 중복 공고와 마감 공고를 제외한 뒤 통계적 시장 신호로 제공하고자 합니다. 각 공고는 사람인 원문으로 이동할 수 있도록 출처를 명확히 표시하며, API access-key는 서버 측 자동화 환경에서만 안전하게 사용합니다.

## 운영 방식

- 무료 공개 베타
- 사람인 원문 공고 링크 유지
- 사람인 출처 명시
- 30분 단위 자동 동기화 예정
- API 결과를 그대로 재판매하지 않음
- 전체 시장을 대표한다고 과장하지 않고 연결된 데이터 범위를 명시

## 승인 후 할 일

1. 발급된 access-key를 GitHub Actions Secret `SARAMIN_ACCESS_KEY`에 저장
2. `Live Job Market Sync` workflow 수동 실행
3. 성공 후 사이트에서 `LIVE INDEX` 및 갱신 시각 확인
4. 사람인 제공 데이터가 노출되는 화면에 `Powered by 취업 사람인` 출처 표시 확인
